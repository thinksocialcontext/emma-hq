# Approvals

Anything that needs the owner's yes goes here as one Markdown file. The dashboard lists every file whose status is `waiting`.

```
---
title: Launch Wednesday ad batch 2026-11-04 (6 stills)
from: ads
kind: ad launch
asked: 2026-11-02
status: waiting
---

What: six new stills, one new ad set, $40 a day.
Where to look: ads/batches/2026-11-04/sheet.jpg and copy.json
Risk: none until launched. Nothing is live.
```

The owner changes `status` to `approved` or `rejected` (or tells HQ, and HQ edits it). Agents act only on `approved`, and record the approval in the ledger.
