# Ad batches

One folder per weekly batch, named by launch date: `2026-11-04/`.

```
2026-11-04/
  plan.md        the experiment card
  spec.json      every string, photo and colour (see ads/docs/how-to-make-ads.md)
  photos/        the real product photos used
  final/         the built stills and a .md record for each
  sheet.jpg      the contact sheet
  critic.md      the critic gate result
  diversity.md   the /rate result
```
