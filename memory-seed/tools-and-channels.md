* Store: Shopify, Woodstock theme. A custom cart modal runs the free pair offer.
* Email: Klaviyo (signup in the footer, added to cart events).
* Reviews: Loox (photo reviews, review wall).
* Ad pixels: Meta, TikTok, Pinterest, Google (GA4 and Google Ads), Microsoft Ads, plus an attribution app. Paid ads have run on several networks.
* Social: Instagram @earringsbyemma, Facebook /earringsbyemma, TikTok @realearringsbyemma, YouTube @EarringsbyEmma (mostly Shorts: behind the scenes, team trends, objection hooks), X @earringsbyemma.
* Blog: "The Plastic Post", very little content so far.

**Why:** agents need to know which tool owns which job before they suggest a new one.

**How to apply:** work inside these tools; propose a new tool only with a reason and a cost. Access keys go in `.env`, never here. See [[owner-approves-everything-external]].
